# Postman

Import the collection and local environment. Fill local secrets, obtain the human subject token through your registered PKCE application, then run in order. The task and credential exchanges use different clients. Request 05 displays the dummy stored credential; do not export real secrets or share token-filled environments. Root namespace is assumed.
